***Superdoku***

**March 2017 – August 2020**

Superdoku is a tool that utilizes computer vision to automate the process for solving Sudoku puzzles. This software application features a visually aesthetic graphical user interface developed with the Unity gaming engine that allows the user to choose to enter the contents of an unsolved Sudoku puzzle or upload an image/snapshot of a puzzle to be parsed by the software. The parsing process uses the Python OpenCV, Keras, and a pre-trained convolutional neural network (CNN) to iteratively classify the set of image regions representing the individual sudoku puzzle digits. After accurately classifying the positions and digits, a backward propagation algorithm is used to then solve the Sudoku puzzle, revealing the result to the user in a UI.
