# res

Static assets for the project (author photo, presentation resources).

## `figures/`

PNG charts generated by
[notebooks/allen_data_606_proposal_eda.ipynb](../notebooks/allen_data_606_proposal_eda.ipynb)
via a `save_fig(fig, name)` helper defined in its Configurations cell. Every EDA visualization in
the notebook saves itself here (150 DPI, tight bounding box) so it can be dropped straight into
presentation slides without re-screenshotting the notebook. Regenerated by re-running the
notebook; not manually maintained.

## `audio_samples/`

A handful of short representative `.wav` clips (via `render_audio_table`'s `save_dir` param,
`AUDIO_SAMPLES_DIR` in the notebook's Configurations cell) so the "Representative Audio Samples"
section plays natively on GitHub: GitHub's notebook viewer strips `<audio>` HTML from cell
outputs outright, but it does render a native playable widget when you open a media file's own
blob page directly, which a plain link survives the sanitizer to reach.

This is a deliberate, narrow exception to the project's usual "keep raw audio out of git"
practice (see [data/README.md](../data/README.md)): a few illustrative clips for this project's
own documentation, not a redistribution of either source corpus. `.gitignore` carves out
`res/audio_samples/*.wav` specifically; everything else under `*.wav` stays ignored.
Regenerated by re-running the notebook; not manually maintained.
